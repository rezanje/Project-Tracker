Hard 2px borders and 4px drop shadows are gone; hierarchy now comes from tone, radius and space. One accent (orange) carries charts and calls to action. Light and dark, mobile and desktop.

Handoff — what changes in the codebase

Token swap — src/styles.css

--bg #f7f4ec→#EDE9E3
--card #ffffff→#FBFAF8
--col #efece1→#F4F1EC
--ink #14241c→#1C1A17
--accent #1f9d55→#E8622C
--radius 10px→24 / 18 / 12px
--shadow-pixel 4px 4px 0→soft --shadow

Rules for the rewrite

  1. Delete the pixel layer. Drop --font-display / Press Start 2P, .display-title, .progress-seg, .btn-pixel, .auth-card, the meadow backdrop and the pixel-icon set. Hanken Grotesk becomes the only face.
  2. No hard borders. border:2px solid var(--ink) on .card / chips / buttons becomes zero border + --shadow. Keep 1px --line for list dividers only.
  3. Segmented bars become continuous. SegBar in home.tsx / projects.tsx → a 5–6px rounded track. segFill() can go.
  4. One accent. The 6-colour ACCENTS[] hashing in Sidebar / Card / index.tsx becomes a warm neutral ramp (#8A7F73 #A8927C #6E7A66 #9C8B7A) for avatars; charts and CTAs use orange alone.
  5. Mobile gets a floating bar + FAB. MobileNav.tsx: 4 items (Home, Center, Tasks, Calendar) in a pill, "More" moves into a long-press / profile sheet, FAB takes the New action.
  6. Keep everything else. Routes, loaders, server functions, dnd-kit wiring, prop contracts and the theme toggle are untouched — this is a render-layer change only.
